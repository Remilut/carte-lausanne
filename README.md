# Fortunes lausannoises 1867–1955 : carte interactive

Carte interactive des contribuables aisés de Lausanne (huit registres d'impôts, 1867–1955).
Projet « Les beaux quartiers : riches et richesse à Lausanne », Université de Lausanne.

## Contenu
- `index.html` : la carte (page d'accueil du site)
- `donnees.html` : politique de gestion des données, accès libre
- `css/style.css` : mise en forme (Helvetica Neue, bleu Catima/UNIL : variables en haut de la section « Theme clair »)
- `js/data.js` : les données de la carte (points, fortunes, calage des fonds)
- `js/app.js` : le fonctionnement de la carte (zoom, corrections, export CSV MN95)
- `images/` : les fonds de carte historiques (Siegfried, plans cadastraux)

## Mettre à jour la carte
Remplacer `js/data.js` (et `index.html` si des corrections ont été enregistrées dedans), puis publier.

## Sources
Registres d'impôts des Archives cantonales vaudoises (K X a 144 à 146). Les positions sont des reconstitutions approximatives.
